
# SpecGuard for AI Agents

SpecGuard is a deterministic validation engine designed to help AI agents work safely and correctly within this repository. It enforces codebase rules, runs verification tools, and prevents security leaks.

## 🚨 Critical Instructions for Agents

As an AI agent, you MUST run SpecGuard validation before finalizing any significant code changes or answering user requests that involve file modifications.

### How to Validate Your Work

Run the following command in the repository root:

```bash
npx specguard validate
```

### Understanding the Output

SpecGuard generates reports in the `.ai/specguard/reports/` directory.

- **Status: PASS**
  - Your changes are compliant.
  - You may proceed with your task.

- **Status: FAIL**
  - 🛑 STOP. Do not proceed.
  - Read the report to understand specific violations (e.g., secrets leaked, forbidden files touched, tools failed).
  - Fix the issues and re-run validation.

### Configuration

SpecGuard rules are defined in `.ai/specguard/spec.yaml`.
- **Global Rules**: Regulate file paths, allowed extensions, and sensitive patterns.
- **Tool Verification**: Defines commands (e.g., `npm run lint`, `npm test`) that must pass.

### Tools & Shell Execution

SpecGuard executes tools securely.
- By default, commands run **without a shell**.
- If a tool requires shell features (pipes, redirects), it must be explicitly configured with `allow_shell: true` in `spec.yaml`.

### Troubleshooting

- **Spawn/Command Errors**: If you see errors related to `spawn` or invalid commands, ensure the tool command in `spec.yaml` is correct and compatible with the OS (Windows/Linux).
- **Missing Script**: If a tool fails because a script is missing, check `package.json` scripts.
