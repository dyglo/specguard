# Security Policy

## Supported Versions

We provide security updates for the latest minor release line (currently 0.2.x). Please upgrade to the latest version before reporting issues.

## Reporting a Vulnerability

If you believe you have found a security issue, please do not open a public issue. Instead, use a private security advisory on GitHub if available.

If private advisories are not available, contact the maintainers through the support channels listed in `SUPPORT.md` and clearly mark the report as "SECURITY".

## Response Timeline

We aim to acknowledge reports within 3 business days and provide a remediation plan as soon as possible.
