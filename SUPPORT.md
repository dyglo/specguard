# Support

## Documentation

Start with the docs at `/docs/README.md`, especially the Quickstart and Reports guides.

## Questions and Discussion

If you have usage questions or design feedback, open a discussion or issue in the repository with clear context and steps to reproduce.

## Bug Reports

When filing a bug report, include:
- SpecGuard version
- OS and Node.js version
- Commands run and full output
- The smallest possible reproduction

## Security Issues

For security concerns, follow `SECURITY.md`.
